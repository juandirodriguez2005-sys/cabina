# Cabina

Plataforma para contratar DJs y fotógrafos: salas y promotores publican bolos, el talento se postula y el pago se hace con Stripe (comisión del 10 % solo al cerrar un bolo). Incluye perfiles con presskit y rider, y una comunidad para seguir y publicar.

- `web/index.html` — la web (un solo archivo, se publica tal cual en Render).
- `supabase/functions/` — funciones del servidor (pagos, registro, webhook).
- `render.yaml` — configuración de publicación en Render.
